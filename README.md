# 지하철 역사심도 지도

전국 도시철도 역의 깊이(역사심도), 지반·레일면 표고, 종단면도를 배경지도 위에서 보는 웹지도입니다.

- 역 위치: 국토교통부 전체 도시철도역사정보
- 깊이·표고: 서울교통공사, 대구교통공사, 대전교통공사, 부산교통공사, 인천교통공사 공공데이터
- 노선 형상: © OpenStreetMap contributors (ODbL)
- 배경지도: VWorld(국토교통부), OpenStreetMap
- DEM 표고: Copernicus GLO-90 (Open-Meteo Elevation API)

서울교통공사 표고는 공사 기준 EL(해발+100m)에서 100을 뺀 값이고, 그 외 역의 지반 표고는 DEM 추정값입니다. 참고용 자료입니다.
